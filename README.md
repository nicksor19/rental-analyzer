# Rental Analyzer

A data analysis project for evaluating and comparing rental properties.

The goal is to use real property and rental data to analyze potential real estate investments.

The finished dashboard could let you select a town and see things such as:
Number of duplexes, triplexes, and small apartment properties
Typical assessed property value
Assessed value per square foot
Age and size of the housing stock
Property-tax burden
Typical local rents from a separate rental dataset
Rent-to-value measures
How one town compares with another
Individual properties that stand out from the local averages
